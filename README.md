# Data Analysis & Feature Selection

A Python-based data analysis project focused on Exploratory Data Analysis (EDA), data visualization, Pearson correlation, Chi-Square hypothesis testing, and feature selection to discover meaningful patterns and relationships within a dataset.

## Technologies Used

* Python
* Pandas & NumPy
* Matplotlib & Seaborn
* SciPy
* Jupyter Notebook

## Key Features

* Data exploration and visualization
* Pearson correlation analysis
* Chi-Square statistical testing
* Feature selection using statistical significance
* Data binning and hypothesis testing

## Objective

To apply statistical techniques and data analysis tools to extract insights and better understand relationships between dataset features.
